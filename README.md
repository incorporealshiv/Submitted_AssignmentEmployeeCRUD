This project is build on java 17 version and spring boot 3.4.2 SNAPSHOT VERSION.
The data base is used MySQL.
The schema name is employee_db_trans and the table name is employee
These are the credentials for making new db connection in MySQL db 
  username root
  password roo

You can change the database at anytime and configure the properties in application properties file in src/main/resource folder

In order to run the project I have taken tomcat 10 embedde jar and the project is Developed using Eclipse IDE.

To run the project, please follow below Steps

1. Clone the project from this repository
2. import the project in Eclipse IDE for J2EE developers
3. Right click on the project
          -> run as srping boot application
4. Once the project is running successfully click on the link below to get the UI of the CRUD Project
5. http://localhost:9092/employees/all-employees
